KeyOverlay 按键屏显
Windows 桌面按键与鼠标屏显。双击 KeyOverlay.exe 运行，需要 .NET Framework 4.x WPF。
默认：Ctrl+Alt+L 锁定；Ctrl+Alt+K 设置；Ctrl+Alt+P 暂停；Ctrl+Alt+H 隐藏。
可在设置中关闭全局快捷键，或用托盘菜单恢复显示和监听。
配置：%LOCALAPPDATA%/KeyOverlayRounded/settings.txt。
演示敏感输入前请暂停显示。源码、构建说明与测试见项目 README.md。
按键名称映射使用 Brook Hong 的 KeyCastOW MIT 许可代码，完整许可见 THIRD-PARTY.txt。
